# Slimebreaker

Slimebreaker is a fast, precision-based 3D platformer built in Unity.  
You play as a small slime trying to conquer brutally hard platforming challenges designed to channel and resolve rage through mastery and movement.

## 🎮 Game Overview

- **Genre:** 3D precision platformer  
- **Engine:** Unity  
- **Perspective:** Primarily third-person  
- **Core Pillars:**
  - Fast, responsive movement
  - Tight, punishing platforming
  - Designed to help players **channel frustration into improvement** through repeatable, skill-based challenges 


## ✨ Features

- ⚙️ **Physics-driven movement** using Unity’s built-in physics engine  
- 🧱 **Challenging platforming** that demands precision and timing  
- 🧩 **Event-driven systems** for things like:
  - Player respawn
  - Collectibles
  - Checkpoints
- 🧠 **Singleton managers** for:
  - Game state
  - Audio
  - Options
  - UI canvases (HUD, menus, dialogue)
- 💬 **Dialogue & NPC interactions** (via a dialogue system package)  


## 🖥 Environment Setup

This section explains exactly how to get the project running on your machine.

### 1. System Requirements

- **OS:** Windows 10/11 or macOS (Intel/Apple Silicon)  
- **RAM:** 8 GB minimum (16 GB recommended)  
- **GPU:** Any GPU that can comfortably run modern Unity 3D scenes  
- **Storage:** ~5–10 GB free space for project + builds  

### 2. Install Required Tools

1. **Git**  
   - Download & install from the official website.
   - Optional but recommended: set up an SSH key for GitHub.

2. **Unity Hub**  
   - Install **Unity Hub** to manage Unity Editor versions.

3. **Unity Editor**  
   - Install the Unity version this project was developed with  
     > Recommended: 6000.0.49f1
   - In Unity Hub → Installs:
     - Add the correct Unity version
     - Include **Windows Build Support (IL2CPP)** or **Mac Build Support** if you want to create standalone builds.
